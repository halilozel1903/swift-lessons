# Security Policy

This is an educational repository. Examples are teaching material, not a security-reviewed application framework.

If you find an ordinary correctness issue, open an issue with a minimal reproduction. For a vulnerability that could expose private data or enable abuse, use the repository’s private vulnerability reporting option when available; otherwise use GitHub’s reporting tools to contact the platform. Do not publish credentials, personal data, or exploit details in a public issue.

Only the current main branch is maintained. Security-sensitive applications require their own threat model, dependency review, input limits, and platform-specific protections.
