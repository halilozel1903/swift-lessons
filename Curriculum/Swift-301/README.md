# Swift 301 — Advanced Language

[Repository home](../../README.md) · [Full curriculum](../../docs/CURRICULUM.md)

## Learning outcome

By the end of this level, build **Reusable Study Toolkit** and explain the tradeoffs in each lesson. Budget approximately 10–15 hours including exercises; progress by demonstrated understanding, not by time spent.

## Lessons

1. [ARC, Capture Lists, and Resource Lifetime](01-memory-ownership.md)
2. [Sequences, Lazy Evaluation, and Key Paths](02-sequences-keypaths.md)
3. [Property Wrappers and Result Builders](03-wrappers-builders.md)
4. [Access Control, Opaque Types, and API Design](04-api-design.md)
5. [Casting, Subscripts, and Conditional Conformance](05-advanced-language.md)

## Level project

Build a generic stack and a protocol-based catalog formatter. Document public access and ownership of a stored callback.

Create your own implementation in a separate practice directory. These are open-ended projects; the included capstone is a worked reference, not a claim that every possible solution is supplied.

## Exit criteria

Explain one generic versus existential choice and prove that callback ownership does not leak.

For each lesson, run the example, make one deliberate change, and explain the result. Revisit any topic for which you cannot predict the behavior. Continue through the [curriculum map](../../docs/CURRICULUM.md).
