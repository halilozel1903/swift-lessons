# Swift 101 — Foundations

[Repository home](../../README.md) · [Full curriculum](../../docs/CURRICULUM.md)

## Learning outcome

By the end of this level, build **Session Calculator** and explain the tradeoffs in each lesson. Budget approximately 10–15 hours including exercises; progress by demonstrated understanding, not by time spent.

## Lessons

1. [Values, Types, and Operators](01-values-types.md)
2. [Control Flow and Pattern Matching](02-control-flow.md)
3. [Optionals and Safe Unwrapping](03-optionals.md)
4. [Collections, Strings, and Unicode](04-collections-strings.md)
5. [Functions and Closures](05-functions-closures.md)

## Level project

Parse optional text durations, reject invalid entries, and report total and average minutes.

Create your own implementation in a separate practice directory. These are open-ended projects; the included capstone is a worked reference, not a claim that every possible solution is supplied.

## Exit criteria

Handle an empty collection and malformed numbers without a crash.

For each lesson, run the example, make one deliberate change, and explain the result. Revisit any topic for which you cannot predict the behavior. Continue through the [curriculum map](../../docs/CURRICULUM.md).
