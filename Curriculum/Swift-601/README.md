# Swift 601 — Engineering and Delivery

[Repository home](../../README.md) · [Full curriculum](../../docs/CURRICULUM.md)

## Learning outcome

By the end of this level, build **Study Planner Capstone** and explain the tradeoffs in each lesson. Budget approximately 10–15 hours including exercises; progress by demonstrated understanding, not by time spent.

## Lessons

1. [Testing Behavior and Failure Paths](01-testing.md)
2. [Architecture and Explicit Dependencies](02-architecture.md)
3. [Performance, Complexity, and Diagnostics](03-performance.md)
4. [Packages, CI, and Release Discipline](04-tooling-delivery.md)
5. [Input Boundaries and Secure Defaults](05-input-security.md)

## Level project

Read, run, and extend the included LearningCore package and study-planner executable. Add an export feature with backward-compatible decoding.

Create your own implementation in a separate practice directory. These are open-ended projects; the included capstone is a worked reference, not a claim that every possible solution is supplied.

## Exit criteria

Keep all verification checks green and add a behavior test for the new feature.

For each lesson, run the example, make one deliberate change, and explain the result. Revisit any topic for which you cannot predict the behavior. Continue through the [curriculum map](../../docs/CURRICULUM.md).
