# Swift 201 — Modeling and Reuse

[Repository home](../../README.md) · [Full curriculum](../../docs/CURRICULUM.md)

## Learning outcome

By the end of this level, build **Course Catalog** and explain the tradeoffs in each lesson. Budget approximately 10–15 hours including exercises; progress by demonstrated understanding, not by time spent.

## Lessons

1. [Structs, Enums, and Invariants](01-structs-enums.md)
2. [Classes, Properties, and Identity](02-classes-properties.md)
3. [Protocols, Extensions, and Dependency Injection](03-protocols-extensions.md)
4. [Errors, Codable, and Boundary Validation](04-errors-codable.md)
5. [Generics and Associated Types](05-generics.md)

## Level project

Model courses with validated durations and enum-based loading state. Inject a catalog source and decode a local JSON fixture.

Create your own implementation in a separate practice directory. These are open-ended projects; the included capstone is a worked reference, not a claim that every possible solution is supplied.

## Exit criteria

Demonstrate value copying, a validation failure, and two source implementations.

For each lesson, run the example, make one deliberate change, and explain the result. Revisit any topic for which you cannot predict the behavior. Continue through the [curriculum map](../../docs/CURRICULUM.md).
