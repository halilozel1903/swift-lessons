# Swift 501 — Apple Application Development

[Repository home](../../README.md) · [Full curriculum](../../docs/CURRICULUM.md)

## Learning outcome

By the end of this level, build **Study Companion App** and explain the tradeoffs in each lesson. Budget approximately 8–12 hours including exercises; progress by demonstrated understanding, not by time spent.

## Lessons

1. [SwiftUI State and Observation](01-swiftui-state.md)
2. [Navigation, Identity, and Accessibility](02-navigation-accessibility.md)
3. [SwiftData and Data Ownership](03-swiftdata.md)
4. [UIKit Interoperability and Platform Boundaries](04-uikit-interop.md)

## Level project

Combine a navigable SwiftUI catalog, an observable progress model, and a SwiftData saved-topic screen.

Create your own implementation in a separate practice directory. These are open-ended projects; the included capstone is a worked reference, not a claim that every possible solution is supplied.

## Exit criteria

Use in-memory previews, show an error state, and verify navigation and large-text accessibility on a simulator.

For each lesson, run the example, make one deliberate change, and explain the result. Revisit any topic for which you cannot predict the behavior. Continue through the [curriculum map](../../docs/CURRICULUM.md).
